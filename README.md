# The Free Rocket Tree Consortium

The Free Rocket Tree Consortium is a loose alliance of contributors from across the open
rocketry ecosystem — software and hardware alike — working toward three things: interoperability
between projects, shared core libraries, and common standards of collaboration.

## The name

- **Free** — free as in freedom, in the tradition of the Free Software Foundation. The tools,
  libraries, and knowledge this community builds should be open for anyone to use, study,
  improve, and share.
- **Rocket** — that part needs no explanation.
- **Tree** — the vision is a platform of interlinked modules — design tools, simulation
  engines, component libraries, flight logging, and more — growing from shared roots and
  branching as the community's needs do. Not a monolith, and not a scatter of disconnected
  projects: an ecosystem where each piece strengthens the others.

Collaboration and contribution are the core values holding it together.

## Why now

We are in an era of AI-assisted development that makes building new tools faster than ever.
That's a fantastic thing — but speed cuts both ways. New projects increasingly spin up to
replicate existing tools with only a few changes of their own, often around portability or UI.
Each one starts from scratch, and each one re-earns (or quietly skips) the validation work the
community has already done.

That energy is better spent building on the community's established, validated work than
duplicating it. That means agreeing on the baselines: common data formats, shared
reference implementations of the hard parts, and clear credit for the people whose methods and
validation the ecosystem rests on.

## What we're working toward

- **Interoperability** — common file formats and interchange standards so designs, simulations,
  and flight data move freely between tools.
- **Shared core libraries** — well-validated implementations of the foundational pieces
  (aerodynamics, flight simulation, motor data) that any project can build on instead of
  rewriting.
- **Standards of collaboration** — conventions for attribution, validation benchmarks, and
  contribution so new work strengthens the ecosystem rather than fragmenting it.

## Get involved

If you maintain or contribute to an open rocketry project — or you're about to start one and
would rather build on proven foundations than reinvent them — we'd like to hear from you.
