# Consortium Social Contract

## Licensing

All software, hardware, static data formats, interchange formats, etc must have open licenses as
approved by the Consortium.

## Open Interoperability

All edges of IO transfer from hardware, software, internet services, etc (wireless transmissions,
serial/usb connections, network services, etc) must be open protocols and documented in a way that other
projects can interface at the IO boundry in a free and open mannor.

All data formats must have open specifications and when licences

## User Control of Information

When user information is stored in closed / proprietary systems, users must be able to download
all of there data in open and pre-published formats.

Users must maintain all ownership and copyright control, although systems may require that the
material is covered licenses from a specified set of open licenses.

Users must be able to remove thier information from services, upto and including complete removal
of all information. *Note: When user information has been integrated into the training of
statistical models there will not be an assumtion that this integration can be removed.*

## Commercialization

Both for and not-for profit commercialization is acceptable where it does not result in closed
systems or restriction of user rights.
